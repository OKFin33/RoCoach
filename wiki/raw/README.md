# Battle Wiki Raw Notes

This directory stores safe, reviewed, source-controlled raw notes for the B
layer.

Allowed:

- PM notes
- reviewed source summaries
- battle review notes
- version observation memos
- provenance metadata

Forbidden:

- secrets
- cookies or sessions
- private raw chats
- copyrighted full-text dumps
- large raw scrape dumps
- unreviewed HTML captures

Raw notes are not automatically safe to commit. Review first.
