# Casebank Pages

Representative tactical cases for pattern teaching.

The casebank should follow:

```text
specs/tactical_casebank_spec.md
```

It should teach patterns, not memorize answers.

Current reviewed pages:

- `balance_bone_dragon_role_compression.md`
- `synthetic_team_review_protocol.md`
- `firefox_wingking_balance_team_reconciliation.md`

Casebank pages are part of B-layer doctrine and may compile into runtime-facing
Battle Wiki exports when they are marked `reviewed`.

They should preserve:

- provenance
- confidence
- correction history when the case reconciles model inference against stronger
  external or PM-reviewed evidence
