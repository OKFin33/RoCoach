## 1. Overview

洛克王国世界是腾讯魔方工作室于 2026 年 3 月 26 日上线的大世界精灵养成手游，PvP 采用回合制 6v6 精灵对战机制。本 Primer 旨在为后续 PvP 分析系统提供最小认知框架，覆盖以下核心内容：

1. **战斗框架**：能量值驱动的回合制对战，技能分为攻击/状态/防御三类，存在"应对"博弈机制
2. **属性系统**：18 种属性，单克制 ×2 / 单抵抗 ×0.5，**双重克制 ×3 / 双重抵抗 ÷3**，无免疫机制
3. **胜负判定**：双方各 4 点魔力值，击败对方精灵扣除魔力，魔力归零失败
4. **队伍构成**：核心输出 1-2 只 + 增益手/减益手/功能位，围绕核心构建配合
5. **环境现状**：主流阵容包括毒队、虫队、星陨队、独角兽强化流、翼王连击流、恶魔狼收割流等

Phase 1 系统仅需理解属性克制关系与联防概念；Phase 2 需引入精灵种族值、技能池、特性；Phase 3 需引入环境使用率与针对关系。

## 4. PvP Minimum Mental Model

### 4.1 战斗的基本结构

**事实**：洛克王国世界 PvP 采用回合制 6v6 对战，双方各携带 6 只精灵，每回合双方各选择一个行动（使用技能、换精灵、聚能）。

**事实**：胜负判定基于魔力值——双方各 4 点魔力值，每击败对方一只精灵扣除对方一格魔力值，魔力值归零或认输则失败。

**推断**：这意味着理论上最多需要击败对方 4 只精灵即可获胜，而非必须全灭。部分精灵的特性（如帕尔的击杀获得额外魔力点数）会改变这一计算。

### 4.2 能量值系统

**事实**：每只精灵有独立的能量值（0-10），技能消耗能量才能释放。技能左上角数字表示能耗。能量在战斗后不会自动回复。

**事实**：可通过消耗一回合进行"聚能"来恢复 5 点能量；聚能算作默认携带的独立状态技能。部分技能和特性也能提供能量回复（如湿润印记每层能耗 -1，光合作用印记每层每回合回能 +1）。

**事实**：大多数精灵在 PVP 语境下上场是满能量，部分精灵受特性影响可能不是。

**推断**：这与宝可梦的 PP 值系统有本质区别——宝可梦的 PP 是每招独立次数限制，而洛克的能量值是共享资源池。这意味着：
- 低能耗技能在持久战中有优势
- 能量压制（消耗/偷取对方能量）是有效战术
- 聚能回合是可被预判和惩罚的时机（聚能可被打断）

### 4.3 技能三分类与应对机制（洛克独有）

**事实**：技能分为攻击类、状态类、防御类共 3 种。

**事实**：应对技可以针对其中一种技能进行应对。应对机制的结算规则如下：

| 己方技能 | 对方技能 | 结算顺序 |
|----------|----------|----------|
| 防御（应对攻击） | 攻击 | 攻击先"出手"，但防御的减伤效果在伤害结算时生效（减伤 50%-90%），然后触发应对成功的额外效果 |
| 攻击（应对状态） | 状态 | 正常按速度结算 |
| 特殊攻击如"地刺"（应对状态+打断） | 状态 | 状态先出手，然后地刺出手，**打断状态使其完全不生效** |

**事实**：应对成功后可能触发额外效果，如"应对攻击：获得全技能威力+40"或"应对状态：下次攻击技能威力翻倍"。存在"应对但不打断"和"应对+打断"两种情况。

**推断**：这构成了洛克王国世界独有的"猜拳式博弈三角"：
- 攻击类技能直接造成伤害
- 状态类技能提供增益/减益
- 防御类技能提供减伤和应对效果
- 应对成功可获得节奏优势，但应对失败则可能浪费行动

**这是洛克王国世界与宝可梦对战的核心机制差异，后续分析系统必须将此纳入考量。**

### 4.4 属性克制在对战中的角色

**事实**：属性克制时伤害 ×2，被抵抗时伤害 ×0.5，无免疫机制。**双属性目标的倍率不是简单乘法**（详见 5.2 节）。

**事实**：游戏数值设计上攻血比较高，克制情况下可以一发满血带走，玩家很难长时间驻场。

**推断**：高攻血比 + 2 倍克制伤害 = 属性克制在洛克王国世界中的权重极高，单次失误可能直接损失一只精灵。这使得：
- 换精灵承接威胁（联防）成为核心战术
- 属性联防分析在 Phase 1 阶段就有实际价值
- 但仅靠属性分析不足以解释完整战斗价值——需要考虑速度、技能、特性、应对博弈

### 4.5 速度与先手系统

**事实**：行动顺序的判定优先级为：**先手等级 > 实际速度 > 随机**。

**事实**：实际速度 = 种族值贡献 + 个体值贡献 + 性格修正（详见附录公式）。

**事实**：当两个精灵实际速度完全相同时，出手顺序**完全随机**。

**事实**：部分技能带有先手加成（如"绝对时间"先手+4，"防御之力"先手+5，"有效预防"应对攻击后先手+1）。

## 5. Attribute and Defensive Core Concepts

### 5.1 属性列表

洛克王国世界共有 **18 种属性**：

普、草、水、火、电、翼、冰、械、地、恶、龙、幽、武、光、毒、萌、虫、幻

与宝可梦对比：
- "萌"对应宝可梦的"超能力/妖精"混合概念，但克制关系不同
- "械"（机械）为洛克独有，对应宝可梦的"钢"但关系有调整
- "幻"为洛克独有
- 无"岩石"单独属性（合并入"地"）

### 5.2 克制倍率规则（重要：与宝可梦不同）

| 关系 | 洛克王国世界 | 宝可梦（对比） |
|------|--------------|----------------|
| 双重克制 | **×3** | ×4 |
| 单克制 | ×2 | ×2 |
| 等倍 | ×1 | ×1 |
| 克制+抵抗抵消 | ×1 | ×1 |
| 单抵抗 | ×0.5 | ×0.5 |
| 双重抵抗 | **÷3 (≈0.333)** | ×0.25 |
| 免疫 | **不存在** | 存在（×0） |

**事实**：双属性目标的倍率**不是简单乘法**。这是洛克王国世界与宝可梦的重要差异。

**示例**：
- 冰系技能打草/翼双属性精灵：双重克制 = **×3**（不是 2×2=4）
- 火系技能打水/龙双属性精灵：双重抵抗 = **÷3**（不是 0.5×0.5=0.25）
- 草系技能打水/地双属性精灵：克制+克制 = **×3**
- 草系技能打水/火双属性精灵：克制+抵抗 = **×1**（相互抵消）

### 5.3 本系加成（STAB）

**事实**：本系加成存在，倍率为 **×1.25**（即威力提升 25%）。精灵使用与自身属性相同的技能时获得此加成。

**与宝可梦对比**：宝可梦的 STAB 是 ×1.5，洛克王国世界的 STAB 较弱（×1.25）。

### 5.4 状态免疫

部分属性自带状态免疫：

| 属性 | 免疫状态 |
|------|----------|
| 草 | 寄生 |
| 火 | 灼烧 |
| 冰 | 冻结 |
| 毒 | 中毒 |

（来源：社区研究截图确认）

### 5.5 联防概念

**定义**：联防指队伍通过成员的属性抗性互补，使每个关键威胁都有对应的换入承接者，从而维持防守节奏的能力。

**宝可梦语境下的联防**：
- 当 A 被 X 技能威胁时，换入 B 承接（B 抵抗 X）
- 当 B 被 Y 技能威胁时，换入 C 承接（C 抵抗 Y）
- 以此形成防守轮转链

**洛克王国世界的适用性验证**：
- ✅ 属性克制倍率高（×2），换入承接有价值
- ✅ 社区攻略中出现"联防""轮转""周转"等术语
- ✅ 存在支持联防/受队打法的技能体系（壁垒、掩护、风墙等）
- ⚠️ 高攻血比可能导致换入成本过高（换入者被直接秒杀），需要数值验证

**事实**：存在联防和受队相关的技能设计：
- **壁垒**：成功应对攻击则冷却 -1，可以实现每回合防御（只要能耗负担得起且一直应对成功）
- **掩护**（虫系）：减伤 70%，紧急脱离（随机换上其他精灵），应对攻击：下个入场精灵获得减伤
- **风墙**（翼系）：减伤 50%，迅捷（若速度比场上敌方快且有需要的能量，则上场即释放），应对攻击

**推断**：联防概念在洛克王国世界中适用，且存在专门支持此战术的技能设计。Phase 1 系统可以基于属性联防进行初步分析，但需要在 Phase 2 引入数值后进行校准。

### 5.6 属性联防分析的价值与局限

**Phase 1 属性联防分析能做到的**：
- 识别队伍的属性弱点集中区（哪些属性缺乏抵抗）
- 识别队伍的打击面盲点（哪些属性打不出克制）
- 提示潜在的联防链条（谁能承接谁的弱点）

**Phase 1 属性联防分析做不到的**：
- 判断换入是否安全（需要数值计算）
- 判断精灵是否能执行联防角色（需要技能池、特性、速度）
- 判断在当前环境中是否有意义（需要使用率数据）

## 6. Team Roles and Tactical Archetypes

### 6.1 角色分工

**事实**：社区攻略中明确提到"一个队伍核心进攻的一般只有 1-2 只，其他的都是围绕这两个主攻手提供帮助"，牵扯到"主攻、增益手、减益手、反印反强化"等角色。

基于社区讨论，当前可识别的角色类型：

| 角色 | 描述 | 示例 |
|------|------|------|
| 主攻/核心C | 队伍的主要伤害来源，通常 1-2 只 | 厉毒修萝（毒队）、恶魔狼（狼王队）、独角兽（强化流） |
| 副攻/副C | 备用输出或补刀收割 | 迪莫（万金油）、翼王 |
| 增益手 | 为队友或自身叠加增益状态 | 天鹅（润泽叠增益）、帅帅魔偶（复制增益） |
| 减益手/挂印记 | 为对手叠加减益印记 | 千棘盔（毒印记）、琉璃水母（毒印记） |
| 反印/驱散 | 清除对方增益或己方减益 | 柴渣虫（驱散）、音速犬（火焰烙印清印记） |
| 功能位/周转 | 提供换入、打断、试探等功能 | 天鹅（周转）、罗隐（地刺打断） |

### 6.2 队伍风格

基于社区讨论，当前可识别的队伍风格：

| 风格 | 核心思路 | 典型阵容 |
|------|----------|----------|
| **毒队/印记流** | 通过叠加毒印记持续消耗，由厉毒修萝收割 | 千棘盔+琉璃水母+裘卡+厉毒修萝 |
| **强化推队** | 通过叠加增益后单核爆发推平 | 独角兽（首领化后折射叠增益）、恶魔狼（吞噬队友强化收割） |
| **控制流/冰冻流** | 通过冻结/控制限制对手行动 | 圣代甜甜+冰钻布鲁斯 |
| **雨天队/天气流** | 利用天气增益提升特定属性输出 | 彩蝶鲨（首领化召唤雨天）+水系输出 |
| **速攻连击** | 高速先手 + 连击技能快速收割 | 翼王（热身+三连击+乘胜追击） |
| **耗能流** | 限制对手能量获取，逼迫对手用低能耗技能 | 花羚羊（清空能量条）+ 降灵印记 |
| **受队/联防轮转** | 通过壁垒、掩护等技能维持防守轮转 | 壁垒+掩护+风墙体系（待开发） |

## 7. Glossary

以下术语按字母/拼音排序，标注来源类型。

| 术语 | 定义 | 来源 |
|------|------|------|
| **壁垒** | 防御技能。成功应对攻击则冷却 -1，可实现每回合防御。 | 洛克术语 |
| **本系加成/STAB** | 精灵使用与自身属性相同的技能时，威力 ×1.25。 | 洛克机制 |
| **打断** | 使对手技能完全不生效的效果。如罗隐的"地刺"可打断聚能和状态技能。 | 洛克术语 |
| **反印/驱散** | 清除对方增益状态或己方减益印记的能力。 | 社区术语 |
| **个体值/天资** | 精灵的个体差异数值。最多 3 项，初始 7-10，PVP 中为初始值 ×6（即 42-60）。 | 洛克术语 |
| **聚能** | 消耗一回合恢复 5 点能量的行动。算作状态技能，可被打断。 | 洛克术语 |
| **克制** | 属性关系。单克制 ×2，双重克制 ×3。 | 洛克机制 |
| **联防** | 队伍通过成员属性抗性互补，分担威胁换入压力的能力。 | 继承自宝可梦 |
| **魔力值** | 胜负判定资源。双方各 4 点，击败对方精灵扣除魔力，魔力归零失败。 | 洛克术语 |
| **能量/能耗** | 技能释放所需资源。每只精灵独立能量池（0-10），战斗后不自动回复。 | 洛克术语 |

| **应对** | 技能机制。应对技针对特定类别技能（攻击/状态/防御），当对手使用被针对类别时触发特殊结算。 | 洛克独有 |
| **印记** | 附着在精灵身上的持续效果（增益或减益）。毒印记、湿润印记等。 | 洛克术语 |
| **增益手** | 为队友或自身叠加正面印记/状态的精灵。 | 社区术语 |
| **种族值** | 精灵物种的基础数值。同一种精灵的同一种形态，种族值固定。 | 洛克术语 |
| **主攻/主C** | 队伍的核心伤害输出者。 | 社区术语 |

## 8. What Phase 1 Needs

Phase 1 定义：仅基于属性关系进行队伍联防结构分析。

### 8.1 必须理解的概念

1. **18 种属性及其克制/抵抗关系**（已有结构化数据）
2. **克制倍率规则**：单克制 ×2，单抵抗 ×0.5，**双重克制 ×3，双重抵抗 ÷3**
3. **联防的基本定义**：队伍成员的属性抗性互补
4. **属性弱点/抗性的定义**：弱点 = 被克制（受 ×2 伤害），抗性 = 抵抗（受 ×0.5 伤害）

### 8.2 可以进行的分析

1. **弱点统计**：队伍对哪些属性存在多个弱点（多只精灵被同一属性克制）
2. **抗性统计**：队伍对哪些属性存在抵抗覆盖
3. **联防链识别**：识别"A 被 X 威胁 → B 抵抗 X"的换入关系
4. **打击面分析**：队伍的技能属性覆盖能打出克制的属性范围

### 8.3 不应该做的判断

1. ❌ 判断换入是否安全（需要数值）
2. ❌ 判断精灵是否适合执行联防角色（需要技能池、特性、速度）
3. ❌ 判断队伍在当前环境中的强度（需要使用率数据）
4. ❌ 预测实际对战中的胜负（需要完整战斗模拟）

### 8.4 Phase 1 输出示例

> "该队伍对冰系存在 3 个弱点（草/地/龙/翼），但仅有 1 个火系抵抗位。建议检查是否有足够的冰系换入承接能力。"

> "该队伍打击面缺乏对机械系的克制（无火/水/武系攻击覆盖），可能面临机械系精灵的压制。"

## 附录 B：数值公式

（来源：B站 新月sama 伤害公式研究截图）

### B.1 伤害公式

**简化公式**：
```
伤害 = 进攻方攻击 ÷ 防御方防御 × 0.9 × 显示威力 × 不稳定加成 × 连击数 × (1-减伤)
```

**详细公式**：
```
伤害 = 进攻方攻击 ÷ 防御方防御 × 0.9 × (技能威力 × 应对倍率 + 固定威力) 
       × 威力提升buff × 本系加成(1.25) × 克制关系 × 能力等级 × 天气影响 × (1-减伤)
```

**能力等级**：
```
能力等级 = (1 ± 我方攻击等级变化 ± 敌方防御等级变化)
```
例：我方物攻 +100%，敌方物防 -100%，最终伤害 ×3（即 1+100%+100%）

**注意**：
- 显示威力 = 对战中技能右下角的威力，已经自动计算了各种加成
- 不稳定加成 = 应对成功的倍率提升、风起印记等（不会自动计入显示威力）
- 多个减伤效果之间**乘算**

### B.2 六维计算公式

**六维**：生命、物攻、魔攻、物防、魔防、速度

**PVP 对战时只受种族值、个体值、性格影响**（无努力值系统）

**生命**：
```
生命 = [1.7 × 种族值 + 个体值 × 0.85 + 70] × (1 + 性格修正) + 100
```

**其他五维**：
```
其他 = [1.1 × 种族值 + 个体值 × 0.55 + 10] × (1 + 性格修正) + 50
```

### B.3 个体值与性格规则

**个体值**：
- 最多 3 项有个体值加成
- 初始值 7-10
- PVP 对战时平衡养成为初始值 ×6，即 42-60
- 满个体 = 60

**性格**：
- 加项 +20%
- 减项 -10%
- PVP 对战时会平衡养成

**速度差距参考**：
- 0 个体和满个体的速度差距 ≈ 30 点种族值
- 以迪莫为例：92 种族值极速 = 118 种族值满速 = 148 种族值无速
